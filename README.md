**Технологияҳо:** PHP 8.2 · PostgreSQL (Neon Cloud) · HTML5 · CSS3 · JavaScript · Chart.js

## 📋 Функсияҳо

- 🔍 Ҷустуҷӯ ва филтри корҳо
- 👁️ Дидани корҳои тасдиқшуда
- ⬇️ Зеркашии файлҳо

### Барои донишҷӯён:
- ⬆️ Бор кардани кори нав
- 👤 Идоракунии профил
- ★ Корҳои дӯстдошта
- ⭐ Реитинг ва тавзеҳ

### Барои омӯзгорон:
- ✅ Тасдиқ/рад кардани корҳо
- 👥 Идоракунии донишҷӯёни худ
- 📊 Омори корҳои худ

### Барои администратор:
- ⚙️ Ҳамаи функсияҳо

- 🔄 Иваз кардани нақш
- 📈 Графикҳо ва омор

- 🛡️ Идоракунии корбарон

## 🚀 Ҷорикунӣ

### Қадами 1: Neon PostgreSQL
1. neon.tech → Sign Up
2. New Project → arxiv-dis
3. SQL Editor → файли `config/schema.sql` иҷро кунед

### Қадами 2: GitHub
1. github.com → New Repository
2. Файлҳои лоиҳаро бор кунед

### Қадами 3: Railway
1. railway.app → Login with GitHub
2. New Project → Deploy from GitHub
3. Settings → Generate Domain
